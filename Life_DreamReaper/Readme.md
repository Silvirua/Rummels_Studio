# Life:DreamReaper

1. 장르 : 2D 횡스크롤 액션
2. 스토리 장르 :

3. 주인공 - 검은 로브, 하얀색에 가까운 회색 눈, 하얀 낫, 위습
4. 조작 : 좌클릭-공격, 우클릭-회피, 스페이스바-점프, wasd-이동

5. 게임진행 중 시스템 :
   무기 추가 장비 - O키를 누르면 낫(소켓 5개가 보임)을 열고, 게임 진행 중 숨겨진 루트 or
                   메인 스토리 진행, 부가 스토리 진행하면서 얻는 구체를 장착 가능.
                   색에 따라서 능력이 다르며, 쿨타임이 존재하는 경우 장착시에만 쿨타임 갱신.
                   현재는 붉은색, 초록색, 파란색, 보라색, 노란색만 구현.
   
   기타 등등은 추가 예정
