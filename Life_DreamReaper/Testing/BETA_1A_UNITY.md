1. UNITY 제작 testing :
         - 2D 횡스크롤
         - 기본키 I키 > 낫에 장착할 수 있는 스킬 셋으로 최대 5개의 스킬 세팅
              : 붉은색 - 5번째의 추가타+확률적으로 즉사
              : 파란색 - 2단 점프 가능
              : 초록색 - 회피 및 퍼펙트 회피 시 추가타 발생
              : 노란색 - 패링 가능
              : 보라색 - 부활패시브 추가, 3분 쿨타임. 장착하지 않을 시 쿨타임 감소 x

2. 인터페이스 디자인 :
  테스트 용이므로, 좌 / 우 로만 디자인
     - 좌 : 본인이 찾은 구슬 목록 (테스트용으로는 모든 색의 구슬을 출력)
     - 우 : 구슬을 장착할 수 있는 낫 이미지. 흔히 말하는 키 세팅 부분

  -> 색이나 디자인 : 복잡하게 하지 않고 색과 테두리 정도만 구현. 구슬 같은 경우에는 입체감을 위해 조금의 음영 추가

3. 출력 예정 부분
     첫째: 본인이 선택한 것 -> 드래그 앤 드랍 형식이 아닌 포인트 앤 클릭 형식. 클릭하면 활성화 되는 방식으로 비어있는 곳부터
                             차례대로 위 오른쪽 아래 왼쪽 중앙 순으로 배치
     둘째: 본인이 선택한 것은 밝게 처리하고 선택하지 않은 것은 왼쪽의 구슬에서 어두운 음영처리를 할 것
     셋째: 인게임은 오직 스킬셋 부분만 처리될 예정. 기타 출력 부분은 아랫쪽 콘솔에서 결과화면을 띄울 것
           -> 본인이 선택하는 것은 활성화처리, 선택하지 않은 것은 비활성화 처리. 즉, 선택 이후 다시 비활성화 시킬 때만
              본인의 선택하던 것에서 비활성화 됨을 출력.
         예) 효율적인 처리 활성화, 빠른 기동성 활성화 중 빠른 기동성을 해제할 경우
           출력 예시 -
                   효율적인 처리:빨강 활성화
                   빠른 기동성:파랑 활성화
                   빠른 기동성:파랑 비활성화

             기존에는 본인이 장착하지 않은 아무것도 없는 상태에서 시작하는데 이때는 모든 것들이 해제되어 있는 상태이며,
             그것들이 활성화 된 이후에 비활성화 되는 것이 아니라면 콘솔 확인 메세지를 출력하지 않는다.

   4. 최종적으로 완성되어야 할 부분
       1) I키를 눌렀을 때 스킬창이 보임(비활성화도 가능)
       2) 스킬창에서 좌 우 구분이 되어 있을 것.
       3) 좌 : 본인이 찾은 구슬들 출력, 우 : 장착할 스킬 창(검은 낫)
       4) 구슬이 활성화 되기 전은 음영이 낮을 것. 구슬이 활성화되면 구슬의 음영이 높아질 것.
       5) 장착했을 때 콘솔 창에서 스킬이 활성화됨과 활성화 이후 비활성화를 출력
